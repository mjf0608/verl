# 室内电视场景下非线性回声消除（AEC）模型建议

## 1. 问题定义
你的当前阶段任务是：

- 输入：
  - 通道1：麦克风混合信号 `d(t)`（用户语音 + 电视回声 + 噪声 + 混响）
  - 通道2：电视播放参考信号 `x(t)`（干声）
- 目标：估计并去除回声分量 `\hat{e}(t)`，得到残差信号 `y(t)=d(t)-\hat{e}(t)`。

关键困难在于：

1. **真实设备链路非线性**（功放/喇叭失真）；
2. **声学路径长且时变**（房间反射、用户移动）；
3. 线性假设失效（`e(t)` 与 `x(t)` 不是简单卷积关系）。

因此需要**双输入（mic+ref）且可建模非线性失真**的神经网络 AEC。

---

## 2. 优先推荐模型：复频域双分支 CRN（Complex CRN AEC）

### 2.1 模型结构
建议采用“**参考分支 + 混合分支 + 融合掩蔽头**”的复频域 CRN：

1. 对 `d(t)`、`x(t)` 做 STFT，得到复谱 `D(f,\tau)`、`X(f,\tau)`；
2. 两个编码器提取特征：
   - Mic Encoder：提取当前语音/噪声/混响上下文；
   - Ref Encoder：提取回声先验（含非线性可由深层卷积+门控拟合）；
3. 在瓶颈层使用 **TCN/Conformer 或 GRU** 建模长时依赖；
4. 融合模块（Cross-Attention 或 FiLM/Gated Fusion）输出复掩蔽 `M(f,\tau)`；
5. 估计回声 `\hat{E}(f,\tau)` 或直接估计近端语音 `\hat{S}(f,\tau)`；
6. iSTFT 回到时域。

### 2.2 为什么它适合你当前场景

- 相比纯线性自适应滤波，CRN 可拟合扬声器非线性；
- 双输入结构天然利用参考通道；
- 复频域建模对相位与混响更鲁棒；
- 可在推理端做轻量化（深度可分离卷积、低维隐藏层）。

---

## 3. 可选增强："线性前端 + 神经残差"混合架构

为提升稳定性，建议工业化采用两级：

1. **一级线性 AEC（如 NLMS/频域自适应滤波）**：先去掉可线性解释的大部分回声；
2. **二级神经网络（CRN/TCN）**：专门学习剩余非线性回声与失配残差。

优点：

- 训练更容易收敛；
- 在强双讲（用户和电视同时说话）下更稳；
- 失真类型变化时泛化更好。

---

## 4. 训练目标（Loss）建议

推荐组合损失（从易到难）：

1. **时域 SI-SNR Loss**（对 `\hat{s}(t)`）；
2. **多分辨率 STFT Loss**（幅度+相位约束）；
3. **回声抑制辅助损失**：对纯回声段最小化残留回声能量；
4. **双讲保护损失**：在近端语音段限制语音失真（防止把人声误杀）。

可用权重示例：

- `L = 0.4 * L_si_snr + 0.4 * L_mrstft + 0.1 * L_echo + 0.1 * L_nearend`。

---

## 5. 数据构建与标注关键点

真实可用效果主要由数据决定，建议：

1. 用多型号电视/音箱实录 RIR 与失真路径；
2. 合成时随机化：
   - 音量、EQ、削波、动态压缩、轻微失真；
   - 房间大小、混响时间、说话人位置；
3. 覆盖 4 类片段：
   - 仅回声；
   - 仅近端语音；
   - 双讲；
   - 噪声主导；
4. 保证参考信号与麦克风信号存在随机延时抖动（模拟系统时钟误差）。

---

## 6. 在线部署建议（电视端）

1. 帧长 20ms，帧移 10ms；
2. 总算法延迟控制在 40ms 内；
3. 参数量优先控制在 1M~5M；
4. 使用 int8/混合精度量化；
5. 增加"保守模式"门控：低置信度时降低抑制强度，避免近端语音失真。

---

## 7. 评估指标（你当前阶段最该关注）

- ERLE（Echo Return Loss Enhancement）
- 双讲下的语音保真（PESQ / DNSMOS / STOI）
- 主观听感：
  - 回声尾音是否可闻；
  - 人声是否有金属音/抽吸感；
  - 电视高音量时是否崩溃。

建议先用 **ERLE + 双讲语音失真率** 作为阶段门槛。

---

## 8. 结论（落地建议）

在你的描述场景下，首选模型为：

- **双输入复频域 CRN/TCN AEC（必要时加 Cross-Attention）**；
- 工程上建议采用 **线性 AEC 前端 + 神经残差后端** 的两级方案。

该路线能在“参考与真实回声存在非线性失配”的电视设备差异场景下，取得比传统线性滤波更稳健的效果，并保留后续扩展到“噪声抑制/混响抑制/唤醒前增强”的空间。

## 9. 代码实现（本仓库）

已在 `examples/audio_aec/` 提供可运行基线实现：

- `linear_aec.py`：NLMS 线性前端；
- `model.py`：双输入复频域 CRN（mic residual + ref）；
- `pipeline.py`：两级串联（线性 + 神经残差）；
- `losses.py`：`SI-SNR + MRSTFT + 回声残留 + 近端保护` 组合损失；
- `train.py`：合成数据最小训练脚本。

快速试跑：

```bash
python -m examples.audio_aec.train --epochs 1 --batch-size 2 --device cpu
```

## 10. 如何训练（实操步骤）

### 10.1 数据格式

使用 `jsonl` 清单，每行一个样本：

```json
{"mic":"/path/a_mic.wav", "ref":"/path/a_ref.wav", "near":"/path/a_near.wav"}
```

约束：

- 三个 wav 采样率一致（默认 16kHz）；
- 建议 16-bit PCM；
- 训练脚本会按固定时长 `seconds` 裁剪/补零对齐。

### 10.2 训练命令

```bash
python -m examples.audio_aec.train_manifest \
  --train-manifest /path/train.jsonl \
  --valid-manifest /path/valid.jsonl \
  --sample-rate 16000 \
  --seconds 4.0 \
  --epochs 20 \
  --batch-size 8 \
  --lr 1e-3 \
  --device cuda \
  --save-dir checkpoints/audio_aec
```

输出 checkpoint：

- `last.pt`：最新模型；
- `best.pt`：验证集最优模型（若提供 `valid-manifest`）。

### 10.3 先跑通再扩展

推荐流程：

1. 先用 1~2 小时数据跑通（看 loss 下降、ERLE 上升）；
2. 再扩大到多设备/多房间数据；
3. 最后做量化、时延和双讲保护调参。
